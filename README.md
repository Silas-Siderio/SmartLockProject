# 🔐 SmartLock IoT com Reconhecimento de Voz Local

## 🇧🇷 Descrição
Este projeto consiste em uma fechadura inteligente com ESP32 capaz de reconhecer comandos de voz **localmente**, sem necessidade de conexão com a nuvem, e controlada remotamente por uma API .NET e aplicativo mobile.

### 🎯 Funcionalidades
- Reconhecimento de voz local (TinyML)
- Controle remoto via API REST (.NET 8)
- Aplicativo mobile Blazor MAUI
- Logs de acesso e controle via Azure IoT Hub
- Comandos suportados: "abrir", "fechar"

### 🔧 Tecnologias
- ESP32 + Microfone (I2S)
- C (ESP-IDF), TinyML
- .NET 8 (C#)
- Azure IoT Hub
- MAUI/Blazor para aplicativo móvel

## 🇺🇸 Description
This project is a smart door lock using ESP32 with **offline voice recognition**. It is also remotely controllable via a .NET 8 API and a mobile app.

### 🎯 Features
- Local voice recognition (TinyML)
- Remote control via REST API (.NET 8)
- Mobile app built with MAUI Blazor
- Access logging with Azure IoT Hub
- Supported commands: "abrir" (open), "fechar" (close)

### 🔧 Tech Stack
- ESP32 + Microphone (I2S)
- C (ESP-IDF), TinyML
- .NET 8 (C#)
- Azure IoT Hub
- MAUI/Blazor mobile app
